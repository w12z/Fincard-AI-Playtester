# Local bridge protocol v1

Transport: TCP on `127.0.0.1`, UTF-8 JSON followed by LF. One outstanding request per connection. Token and port are generated by the launcher and passed through `FINCARD_BRIDGE_TOKEN` / `FINCARD_BRIDGE_PORT`, never CLI arguments or saved logs. Requests are limited to 64 KiB. Do not expose the port to a network.

## Observe

```json
{"token":"...","method":"observe"}
```

Response: `{"ok":true,"observation":{...}}`.

Observation includes protocol version, opaque `revision`, player-visible state, current decision and `legal_actions`.
It does not expose deck order, RNG state, future random events, or seed. The revision may change after manual input or animation; its only meaning is freshness.

Each in-game observation includes `scenario_description`, `goal`, `goal_conditions`, `failure_conditions`, and `goal_timing` (deadline, earliest win and remaining turns). At the user's request, `fixed_event_forecast` also supplies deterministic scenario milestones: turn, phase, title and description. It is an explicit playtest briefing shown in the dashboard, not a prediction of random outcomes. Event choice effects and reward draws are not revealed in advance.

## Act

Copy one entire action from the latest observation:

```json
{"token":"...","method":"act","revision":12,"action":{"kind":"end_turn"}}
```

On success the normal game UI executes the action and the bridge responds after the animation settles with an updated observation. Rejected requests return `{"ok":false,"error":"..."}` and do not execute a fallback action. Stale requests must be discarded and re-observed; do not blindly retry them.

Action kinds: `start_run`, `play_card`, `end_turn`, `use_aid`, `resolve_event`, `claim_reward`, `choose_removed_card`, `choose_retained_card`, `choose_review_card`, `choose_discard_card`.

Never synthesize fields or indices: choices, reward tokens and legal skips are explicitly included in `legal_actions`.
An empty legal list during animation means wait; a terminal `run_status` of 1 or 2 means won or lost.

## Screenshot

```json
{"token":"...","method":"screenshot"}
```

Response: `{"ok":true,"png_base64":"..."}`. Captures only the game's viewport, not the desktop, other windows or the control panel. No caller-specified file path is accepted.

## Isolation

This is an opt-in external `SceneTree` script; no game plugin, autoload, rule patch or project configuration edit is installed. The launcher starts a dedicated game process. Closing it does not terminate unrelated Godot or Fincard processes.
